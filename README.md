## How to Use

1. **Open the app** -
2. **Upload a label** - drag and drop one or more alcohol beverage label files onto the upload area, or click to browse. Supported formats: JPG, PNG, PDF, TXT.
3. **Enter application data** *(optional)* - if you have COLA application data for the label, enter the relevant fields on the next screen to enable label-vs-application comparison. Skip this step to run a standalone label check.
4. **Run the analysis** - click Analyze. The tool processes each label automatically and displays a detailed compliance report within seconds.
5. **Review results** - each label receives a Pass, Fail, or Needs Review status per field, with a full explanation. Export the report as CSV or PDF using the buttons on the results screen.

## Supported File Formats

| Format | Notes |
|---|---|
| JPG / PNG | Standard label photographs or scans |
| PDF | Scanned label documents |
| TXT | Plain-text label content |

Maximum file size: 10 MB per file. Batch uploads supported.
